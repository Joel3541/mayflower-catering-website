# Drop real photos here

Put Mayflower's own photos in this folder, then tell Claude Code the folder is
ready. They will be resized, compressed, renamed, given alt text, wired into
the page and pushed. Nothing in this folder is published as-is.

## What to shoot or find

Originals only. Do NOT re-download from Facebook or WhatsApp - both
re-compress heavily, and Facebook's grid thumbnails serve at 206x206, far too
small for this site.

Best sources, in order: the original phone/camera files, an event
photographer's delivered files, then anything else.

## What's needed (15 slots)

| Priority | Shot | Fills |
|---|---|---|
| 1 | A signature dish, close, well lit | Gallery + about collage |
| 1 | A full buffet / chafing dish line | Hero + gallery |
| 1 | A real catered event, guests visible | Gallery |
| 2 | Team or chef at work in the kitchen | About section, left column |
| 2 | 3-4 more plated dishes, varied | Package cards |
| 3 | Table settings, drinks service, venue | Gallery |

Fewer good photos beat fifteen weak ones - a strong shot can be reused across
slots, and a blurry one costs more credibility than the stock image it
replaces.

## Practical shooting notes

- Daylight near a window or outdoors beats indoor electric light
- Shoot from slightly above for plates, eye level for buffet lines
- Landscape orientation for most slots; one tall portrait for the chef shot
- Get permission before publishing photos with recognisable guests' faces
- Largest file size the phone offers; don't crop before sending

Any format is fine - JPG, PNG, HEIC. Any size. Oversized is good; they get
resized here.
